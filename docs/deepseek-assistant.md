# DeepSeek 填写助手

## 用法

1. 平台管理员登录 SaaS；右下角点击「DeepSeek 助手」。本版不向普通商户成员开放，避免共用平台密钥造成未经授权的调用费用。
2. 首次使用在窗口里点击 DeepSeek 开放平台链接，使用自己的账户创建 API Key。它不是登录密码；API 消费及余额归该 DeepSeek 账户。
3. 只在助手的「DeepSeek API Key」密码框粘贴密钥，点击「加密保存密钥」。不要发到聊天或填写进微信连接。
4. 勾选同意发送主动输入的问题，输入不懂的字段或操作，点「发送问题」。第一次回答成功才说明密钥、余额和调用权限可用；保存成功不等于验证成功。
5. 「子商户入驻」文本字段旁的「不会填？」会打开助手并选定字段，但不会自动发送问题或表单内容。
6. 按助手解释查找真实资料，在原表单填写并核对；助手不代填、不代提交、不发起支付，也不能保证过审。

## 数据与费用边界

- 仅发送主动输入的文字和最近三轮简短对话，以及服务器内置的页面/字段说明；不读取真实表单值、照片、商户数据库或连接凭据。
- 不支持上传证件图片。不要把身份证号、银行卡号、密码、密钥粘贴到问题中；服务端会额外遮盖可识别的手机号、邮箱、长号码和部分密钥格式，但不能保证识别所有个人信息。
- 密钥经已有 AES-GCM 工具加密后写入服务器 `.data/assistant/deepseek.enc`，文件权限为 0600，不回显，不写浏览器存储。该文件应与平台加密主密钥一起按现有敏感配置备份策略管理。
- 页面切换商户空间、账号或刷新后清空对话；服务端不建立聊天记录表，不记录问题或回答日志。
- 只向固定的 `https://api.deepseek.com/chat/completions` 请求，不接受任意代理地址、工具调用或模型指令执行。默认模型 `deepseek-flash`、关闭思考、最多2048输出tokens。
- 需要平台管理员会话、CSRF及每次发送同意标识。输入限长，单请求最大64KB；每账号每分钟8次、每小时60次；进程内所有账号每日合计200次，最多2个并发、同一账号同时1个请求。
- 上述频率窗口属于单进程保护，API进程重启会重置，不是DeepSeek账户硬预算。正式扩大使用前，应在供应商侧设置支出管理，并改为共享持久化配额。
- 超时或失败不自动重试，避免重复计费；用户手动重发仍可能再次计费。401提示密钥问题，402提示余额，429提示繁忙，不透传供应商错误正文。
- 本版无实时联网检索。涉及类目、费率、结算规则ID、审核等易变要求，需核对微信官方说明，不应直接依赖AI回答。

接口依据：[DeepSeek 首次调用](https://api-docs.deepseek.com/)、[Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)。
