## 用户接下来怎么操作

1. 用原管理员账号登录现有后台。
2. 如菜单未刷新，按 `Ctrl+F5` 强制刷新。
3. 选择门店所属商户空间，进入「子商户入驻」。
4. 新建缔丝风尚草稿并保存；此时不向微信发送资料。
5. 核对经营者授权、服务商进件权限和行业结算规则后，再另行批准开启真实提交。

填写步骤见 [子商户入驻操作说明](merchant-applyment-runbook.md)。
