# “附近到店惠”微信小程序审核填报口径

## 必须统一的主体定位

- 小程序名称：附近到店惠
- 运营主体：漯河逐梦网络科技有限公司
- 服务类目：软件开发
- 不选择：美容美发、丽人等自营门店类目
- 平台定位：基于用户授权位置展示附近入驻门店及优惠信息的软件平台
- 履约主体：具体到店服务由入驻商家提供，平台自身不是美容美发门店

“美容美发”仅是个别入驻商家的实际经营类目，不是“附近到店惠”平台小程序的服务类目。

## 小程序介绍

附近到店惠是结合用户授权位置，展示附近入驻门店、门店详情及优惠信息的本地生活服务平台。

## 版本审核备注（200字以内）

“附近到店惠”由漯河逐梦网络科技有限公司开发运营。平台结合用户授权位置，展示附近入驻门店、门店详情及优惠信息，为商家提供软件开发、技术支持和信息展示服务。平台不自营美容美发门店，不直接提供美容美发服务，具体到店服务由相应入驻商家提供。本次提审类目为“软件开发”。

## 审核人员测试路径

1. 打开小程序进入“附近门店优惠”页面。
2. 点击“查看我附近的门店”，授权位置后按距离浏览入驻门店。
3. 也可以搜索门店名称或扫描门店二维码。
4. 点击任一入驻门店，查看门店详情及优惠信息。

## 禁用表述

不要使用“本店”“我店”“本店主营美发”“我们的美容美发门店”等表述。统一使用“平台”“入驻门店”“由入驻商家提供服务”。
