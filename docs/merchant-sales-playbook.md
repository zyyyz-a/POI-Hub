# POI Hub 商家沟通与成交话术

版本：V1.0（单店受控试点版）  
更新日期：2026-08-25  
适用对象：销售、地推、招商主管、店铺运营人员  

> 本话术只用于如实介绍服务，不承诺审核、流量、销量或收益。消费者买券款由微信小店按其规则收取和结算给商家；POI Hub 只向商家另行收取软件/运营服务费。

## 1. 先记住这一句话

我们帮助实体店把“微信里的门店位置、团购商品、订单券码、到店核销和对账”整理到一套运营流程里，让店员更容易执行；消费者的钱仍走商家自己的微信小店账户，我们不代收、不截留消费者货款。

## 2. 什么商家适合谈

优先联系：

- 有固定经营地址、营业执照和真实门头的实体店。
- 愿意开通或已经开通微信小店。
- 愿意配合完成微信本地生活及类目资质审核。
- 有清晰的到店服务项目和价格，例如染发、烫发、护理、剪发套餐。
- 能安排一名负责人处理审核电话、资料补充、测试下单和试核销。

暂时不要承诺马上上线：

- 没有营业执照，或营业主体与门店、收款账户明显不一致。
- 经营地址、门头、地图位置不真实。
- 要求我们代持顾客货款、绕过微信审核或制作虚假材料。
- 坚持“先保证多少订单/营业额再付款”。
- 不愿说明退款、预约、加价和使用限制。

## 3. 30 秒开场话术

老板您好，我们做的是微信本地生活门店运营接入。简单说，就是协助您把腾讯地图上的门店、微信里的门店展示、团购套餐、顾客券码核销和后续对账串起来。顾客买券的钱还是进您自己的微信小店结算账户，我们收的是另外约定的服务费。我们可以先用一家店做试点，先检查资料和开通条件，能做再签，不跟您承诺虚假流量和收益。您方便给我三分钟，我先了解一下店铺情况吗？

## 4. 三分钟面谈话术

销售按顺序说，不要一上来就报价。

### 第一步：问现状

“老板，我先确认几个情况，这样才能判断能不能做：您有营业执照和固定门头吗？微信小店开通了吗？腾讯地图能搜到门店吗？现在有没有线上团购？平时到店核销是谁负责？”

### 第二步：说问题

“很多门店不是没有项目，而是门店位置、商品、券码、核销和账单分散，员工不知道从哪里看，出了退款或核销失败也不知道找谁。我们做的是把这套流程标准化，并保留操作记录。”

### 第三步：说价值

“我们会协助整理资料、建立标准门店、处理腾讯地图/微信服务 POI、配置团购商品，并给店员一套核销和异常处理流程。总部能看到待审核、失败操作、库存和对账差异。”

### 第四步：讲清资金

“顾客购买团购券，付款和结算仍由微信小店承载，结算到商家自己的微信小店账户。我们不会把顾客买券钱收进自己的账户。我们的费用是您和我们单独约定的开通费、系统服务费或代运营费。”

### 第五步：降低决策压力

“我们建议先上一家店、一个简单商品、少量库存，完成一次真实购买、核销、退款或撤销演练，再决定是否扩大。审核时间和是否通过由微信/腾讯决定，我们负责资料检查、提交和跟进，不说百分之百通过。”

### 第六步：推进下一步

“如果您愿意，我们今天先做免费条件检查。您提供营业执照主体、门店地址、联系电话、门头和环境照片、营业时间、准备上线的项目和价格。检查没有明显问题后，我们再给正式服务清单和报价。”

## 5. 十五分钟成交脚本

### 5.1 建立信任

“我先把边界说在前面：我们不是微信官方，也不卖所谓内部名额。开店、类目和商品是否通过，以微信和腾讯审核结果为准。我们提供的是接入、资料整理、系统和运营执行服务。”

### 5.2 用五个问题判断需求

逐项记录，不要凭记忆：

1. 门店主要想卖什么到店项目？
2. 哪些项目成本稳定、员工都能交付？
3. 是否需要预约？哪些日期或时段不能使用？
4. 是否可能产生到店加价？什么条件下加价？
5. 谁负责接审核电话、查看订单和核销券码？

### 5.3 给出试点方案

“按您店里的情况，建议第一阶段只做一个门店、一个低争议套餐、一个 SKU。我们先把门店位置和资质跑通，再提交商品；商品通过后只放少量库存，完成一笔内部真实测试。测试通过后才正式宣传。”

美发门店可优先考虑结构清楚的项目，例如：

- 单人基础洗剪吹套餐；
- 单人基础护理套餐；
- 明确长度、药水档位和加价边界的染发或烫发套餐。

不得使用“到店再说”“所有长度通用但实际加价”等模糊规则。商品名称、详情、价格、预约规则和门店执行口径必须一致。

### 5.4 报价话术（把空格填好再用）

“本次费用分开列，不从顾客货款里扣：一次性开通/实施服务费为 ¥____；系统服务费为 ¥____/月（或 ¥____/年）；如果需要我们持续代运营，另为 ¥____/月。服务内容、付款节点、退款或终止条件都写进确认单。微信官方可能产生的费用，以微信后台实际账单为准，不算作我们的服务费。”

### 5.5 收口成交

“今天您只需要决定是否进入资料检查，不需要先承诺扩大门店。资料检查通过后，我们把服务范围、价格和双方责任写清楚；您确认并完成第一阶段付款后开始实施。上线前您还会做最终商品和价格确认。”

## 6. 电话/微信跟进模板

### 首次添加微信

老板您好，我是____。今天和您沟通的是微信本地生活单店试点：协助整理腾讯地图/微信门店、团购商品、券码核销和对账流程。顾客买券款由微信小店按规则结算给您，我们只收双方约定的服务费。为了先判断能否接入，请您有空时提供：营业执照主体名称、门店全称、详细地址、负责人电话、营业时间，以及门头/店内环境照片。敏感账号密码、AppSecret、支付密钥请不要通过微信发给我。

### 资料未齐提醒

老板您好，您店的接入资料目前还差：①____；②____；③____。资料补齐前我们不会提交审核，避免因为信息不一致反复驳回。请直接发缺少的普通资料即可；身份证完整照片、账号密码、AppSecret、支付密钥等敏感信息请按我们提供的安全方式由负责人本人操作，不要发在群里。

### 审核中说明

“资料已经提交，目前状态是‘审核中’。审核由微信/腾讯完成，时间和结果不是我们能保证的。此阶段请保持审核电话畅通，不要重复提交或随意修改主体、地址和名称。收到补充或驳回原因后发给我们处理。”

### 上线前确认

“请您最后确认商品名称、售价、市场价、服务内容、预约方式、不可用时间、加价条件、退款口径、适用门店和初始库存。您书面回复‘确认上线’后，我们再上架。”

## 8. 商家必须确认的六个事实

让商家逐项回复“已知悉”：

1. POI Hub 不是微信官方，审核结果以微信/腾讯为准。
2. 不保证流量、订单、排名、销量或利润。
3. 消费者货款由微信小店处理并结算给商家，POI Hub 不代持。
4. POI Hub 服务费单独支付，费用项目和期限写入合同/确认单。
5. 商家对营业资质、商品内容、价格、履约、退款和员工操作负责。
6. 商家不得提供虚假地址、照片、资质或借用他人主体。

## 9. 绝对禁止的销售说法

- “微信官方合作、内部渠道、绿色通道”，除非确有可核验的书面授权。
- “百分百开通、百分百审核通过、永久不封”。
- “保证流量、保证曝光、保证订单、保证回本”。
- “顾客的钱先到我们，再给商家”。
- “微信扣的佣金就是我们的服务费”。
- “不用微信小店、不用本地生活审核也能上”。
- “资料随便做一套就能过”。
- “把账号密码、短信验证码、支付密钥发给我”。

## 10. 销售交接给运营的标准

只有以下项目全部具备，销售才能把商户标记为“可实施”：

- [ ] 商家主体、门店和签约方名称一致，差异已书面说明。
- [ ] 服务范围、价格、付款节点和不保证事项已确认。
- [ ] 门店全称、详细地址、负责人电话、营业时间完整。
- [ ] 门头、环境、营业执照等普通材料清晰可用。
- [ ] 商家知道微信小店和本地生活需要单独申请审核。
- [ ] 商家指定了一名能接电话、处理补件和完成测试的人。
- [ ] 未在聊天或表格中收集账号密码、验证码、AppSecret、支付密钥。
- [ ] 销售没有作出“包过、保量、代收货款”等承诺。

未满足任何一项，退回销售补齐，不允许运营凭猜测继续。
